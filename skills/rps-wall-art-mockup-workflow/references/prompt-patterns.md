# Prompt Patterns

## Blank Placeholder Interior

```text
Modern editorial interior wall art mockup for Rock Paper Scissors.
Scene: <room/context>.
Frames: <count, orientation, relative size>.
Artwork areas: blank solid <color> placeholders only, no artwork, no text, no logos.
Style: natural light, believable scale, restrained styling, art-forward composition.
Avoid: generated paintings, artist-style imitation, stock-photo gloss, clutter, watermarks.
```

## Shopify Listing Context

```text
Clean product-context wall art mockup for a Shopify listing.
Scene: <room/context>.
Frame/layout: <single print/set/diptych/triptych/gallery wall>.
Artwork areas: blank placeholders only, ready for compositing real RPS artwork.
Composition: product is easy to understand at thumbnail size; enough room context for scale.
Avoid: physical frame claims, fake matting that conflicts with product, text, logos, watermarks.
```

## Marketplace Variant

```text
Marketplace-ready wall art mockup for <channel>.
Scene: <room/context>.
Artwork areas: blank placeholders only.
Composition: clear thumbnail read, uncluttered, product-forward.
Avoid: platform logos, fake sale badges, excessive props, generated artwork.
```

## Review Board Prompt

Ask for a contact sheet or review board with labeled options:

```text
Create a clean review board showing options A1-A3.
Include filename labels under each image.
Use a white background and simple black labels.
No decorative title treatment.
```
