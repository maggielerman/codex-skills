# Motion Review Rubric

Score each animation from 1 to 5. A production candidate should not have any score below 3, and expressive motion should average 4 or better.

## Criteria

1. Intent: Does the motion have a job?
2. Continuity: Does the viewer understand what changed?
3. Timing: Does it finish before the user wants to act?
4. Easing: Does it avoid robotic or default-looking movement?
5. Hierarchy: Do important elements lead less important ones?
6. Restraint: Would the page improve if this motion were reduced?
7. Distinctiveness: Does it feel authored rather than template-like?
8. Responsiveness: Does it still work on mobile?
9. Accessibility: Does it respect reduced motion?
10. Performance: Does it avoid layout-heavy animation unless justified?

## Review Output Shape

When critiquing motion, report:

- Intent: what the motion is trying to do.
- Profile: selected taste profile.
- What works: concrete positive behaviors.
- What fails: visible defects or taste mismatch.
- Refinement: specific changes to timing, easing, distance, stagger, sequence, or reduced-motion behavior.
- Verification needed: browser, viewport, interaction, or reduced-motion checks.

## Blocking Defects

Treat these as blockers, not polish:

- Decorative lines, masks, paths, or nav motion overlap readable content.
- Motion delays primary controls.
- Reduced-motion mode is missing.
- Text clips, wraps badly, shifts layout, or becomes unreadable during animation.
- Scroll interaction traps the user or hides the next section.
- Console errors or framework overlays appear during the animation.
