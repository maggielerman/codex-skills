# Product Docs

Product docs pack scaffolding is optional unless invoked through a product-docs compatibility skill.

If enabled, create or update:

- `DOCS/product/README.md`
- `DOCS/product/product-brief.md`
- `DOCS/product/lean-canvas.md`
- `DOCS/product/prd.md`
- `DOCS/product/decision-log.md`

Use `assets/templates/product-docs/product-doc-templates.md`.

Keep changes minimal when existing files already have structure. Product docs should connect product intent to project lifecycle docs, roadmap entries, and decision logs rather than becoming a separate planning system.
