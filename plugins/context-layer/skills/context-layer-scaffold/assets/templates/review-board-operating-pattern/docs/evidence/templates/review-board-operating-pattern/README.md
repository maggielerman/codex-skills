Use this directory for reusable Review Board Operating Pattern scaffolding. The workflow supports UI, design, evidence, content, asset, catalog, and other visual comparison work.

Generated review packets do not live here. If a review packet is intentionally preserved, store it under the owning project's evidence directory.
