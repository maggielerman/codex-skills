# Content Calendar

This calendar tracks planned content before any external publishing step. The external system can remain the source of truth for published content, while briefs, QA plans, visual requirements, and review status live here first.

## Cadence

- Publish target: `1 item per week`.
- Preferred publish day: Tuesday.
- Draft review window: prior Thursday or Friday.
- Final QA window: prior Monday.
- Do not publish until the item has reviewed assets, verified links, and final source-of-truth copy.

## Rules

- Keep each item tied to one reader, buyer, operator, or release decision.
- Prefer contextual internal links where they are relevant over end-of-item link piles.
- Comparison items need current source checks before drafting.
- Process or checklist items need at least one useful visual, table, or proof artifact.
- Every publish candidate needs final asset review and link QA before external publishing.
