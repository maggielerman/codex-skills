# Lean Canvas: Codex Skills Packs

## Problem
- Codex workflows are hard to package and reuse reliably.
- Customers need practical setup and troubleshooting docs, not only skill source files.

## Customer segments
- Agent-forward software teams.
- Solo builders who want mature repo operating patterns.
- Agencies or consultants productizing repeatable Codex workflows.

## Unique value proposition
Installable, documented Codex workflows that carry Maggie's operating patterns into customer repositories.

## Solution
- Portable skill folders.
- Custom plugin backups.
- Generated customer-facing catalog pages.
- Support docs focused on implementation in customer repos.

## Channels
- Direct sales.
- Private repo or packaged distribution.
- Docs-site marketing and onboarding.

## Revenue streams
- Paid pack access.
- Optional support or updates tier.

## Key metrics
- Pack purchases.
- Successful customer installs.
- Docs self-serve resolution rate.
- Repeat support questions converted into docs improvements.
